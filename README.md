# الشاهد الأخير — THE LAST WITNESS

تجربة رعب نفسي تفاعلية باللغة العربية. القصة والشخصيات والتسجيلات خيالية بالكامل؛ لا يطلب الموقع صلاحيات الكاميرا أو الميكروفون أو الموقع أو الملفات، ولا يحتاج إلى خادم خلفي أو حساب.

## التشغيل

يتطلب المشروع Node.js بإصدار متوافق مع Vite 8. من مجلد المشروع:

```bash
npm ci
npm run dev
```

لإنشاء نسخة الإنتاج ومعاينتها:

```bash
npm run build
npm run preview
```

الصور والخطوط والأصوات المستخدمة في التجربة ملفات محلية ضمن `src/assets`. تحفظ الجلسة والإعدادات في التخزين المحلي للمتصفح. يمكن استئناف الجلسة أو إعادة التجربة، كما يمكن مسح التقدم من صفحة التقرير. تعمل التجربة حتى إذا حظر المتصفح التخزين، لكن الاستئناف لن يكون متاحًا بعد إغلاق الصفحة.

## تنظيم المشروع

- `src/pages`: شاشات التجربة من البداية إلى النهايات.
- `src/components`: الواجهة والمشاهد وأرشيف الأدلة وعناصر التحكم.
- `src/data`: الأسئلة والقصة والأدلة والأحداث وقواعد النقاط والنهايات.
- `src/engine`: إدارة الصوت والتخزين والمنطق والتقرير وتحميل الصور.
- `src/hooks` و`src/providers`: حالة الجلسة والإعدادات.
- `src/styles` و`src/assets`: نظام التصميم والوسائط المحلية.
- `tools`: أدوات اختبار المسارات وبناء الأصول.

لا تُختار النهايات عشوائيًا؛ تنفذ القواعد في `src/data/scoring.ts` وتُقيّم الحقيقة المحظورة أولًا. يمكن فحص وصول النهايات باستعراض مسارات الإجابات:

```bash
TSX_TSCONFIG_PATH=tools/tsconfig.tools.json npx tsx tools/paths-test.ts
```

تتوفر إعدادات للصوت ومستوى الصوت والحركة والوميض، ويُحفظ التقدم على الجهاز فقط. للحصول على دعم توجيه الروابط عند النشر على خادم ثابت، اضبطه بحيث يعيد توجيه المسارات غير المطابقة للملفات إلى `index.html`.

## النشر على Vercel

المشروع جاهز للنشر كموقع ثابت (Vite). إعدادات Vercel الموصى بها:

| الإعداد | القيمة |
| --- | --- |
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm ci` |
| Node.js Version | 20.x أو أحدث |

ملف `vercel.json` يتضمن قاعدة `rewrites` التي تعيد توجيه كل المسارات إلى `index.html`، وهذا ضروري لعمل التنقل بين الصفحات (`/start`, `/register`, `/session`, `/archive`, `/confrontation`, `/revelation`, `/ending`) عند فتح الرابط مباشرة أو تحديث الصفحة.

لا يحتاج المشروع إلى أي متغيرات بيئة أو قاعدة بيانات؛ كل الحالة تُحفظ في `localStorage` داخل المتصفح.
